HyperZ UI

Clean, modern, and powerful UI library for Roblox scripts.
Build beautiful interfaces with just a few lines of code.

Get Started YouTube Channel

1. Load the Library

Paste this at the top of your script to load HyperZ UI.

Loadstring 
loadstring(game:HttpGet("https://raw.githubusercontent.com/Itskyanscripts/Ui/refs/heads/main/LoadMainUI"))()

2. Create a Window

Every UI starts with a window.

Lua 
local HyperZ = getgenv and getgenv().HyperZ or _G.HyperZ
local Window = HyperZ:CreateWindow({
    Name = "+1GamesScript"
})

3. Create a Tab

Tabs organize your features.

Lua 
local Tab = Window:CreateTab("Main", "home")

4. Create a Section

Sections group related elements together.

Lua 
Tab:CreateSection("Features")
